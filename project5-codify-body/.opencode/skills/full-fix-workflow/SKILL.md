# Full Fix Workflow

## What This Does
This is a dynamic workflow that runs the entire maker-checker body in ONE command.

## Steps
1. Run tests to see what's failing
2. Find and fix the bug
3. Review the fix
4. Give a verdict (PASS/FAIL)

## Output
Report the fix and whether it passed review.

## Rules
- Fix the bug, don't change the tests
- Make the smallest change possible
- Run tests to verify your fix works
- Give a fair review
